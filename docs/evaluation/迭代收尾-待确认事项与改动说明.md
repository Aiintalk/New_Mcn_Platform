### 2. `8f22778` 标签筛选不生效（你 8/19 报）

**现象**：测试集页选"真实数据"标签，列表无变化。
**根因**：纯前端漏接线——`tagFilter` 状态存在但从未传给 API（后端本就支持 tag 参数）。
**修复**：选标签→请求带 tag + 重置回第 1 页；顺带修了"筛选后标签下拉选项消失"的连带问题。
**验证**：单测 10/10（含 2 回归）+ 浏览器实测（选"真实数据"→共 10 条，清空→共 23 条）。

### 3. `b5e7479` "进行中"看不到新 run（你 8/19 报）

**现象**：新建运行后"进行中"tab 空。
**根因**：语义错位——新 run 先进队列（status=pending），"进行中"只筛 running，排队期不可见，误导以为创建失败。
**修复**："进行中" = pending + running（tab 筛选 + 统计卡片同步）。
**验证**：单测 9/9（含回归）+ 浏览器实测。顺带确认了 run 执行链路本身正常（单 case 约 3-5 分钟：kimi 生成 + glm 四维评分，10 case 全跑约 30-50 分钟）。

### 4. `0d6c4e3` 详情页白屏（你 8/19 报"pending 点查看啥也没有"）

**现象**：run 详情页整页空白。
**根因链**：分数字段是 PG `Numeric`（Decimal）→ FastAPI 序列化成 JSON **字符串** `'9.00'` → 前端当数字调 `.toFixed(1)` → 一个格子崩整页白（无错误边界）。
**修复**：后端根因修（分数/权重统一 Decimal→float，API 返回真数字）+ 前端防御（聚合处 Number() 包裹）。
**验证**：后端 eval router 45 过 + RunDetail 17 过 + 浏览器实测（run 详情恢复：统计卡片 + 5 行评分明细 + 0 console error）。

### 5. `2822328` 运行名被丢弃（你 8/19 报"起的运行名在哪")

**现象**：新建运行填的名字（表单还标必填）列表里看不到，全是 `run-v1.3-行动引导-manual` 默认名。
**根因**：后端 `POST /runs` 没读 body 里的 name，建 run 时硬编码默认名。
**修复**：router 读取 name（空白视为未填）→ scheduler 透传存库；不填才用默认名。
**验证**：scheduler 单测 13/13（+3 回归：透传/未填默认/纯空白默认）+ eval router 45 过 + E2E（建名"E2E-运行名透传验证"的 run → DB 与列表第一行均显示）。
