## 3. 手工测试（真实 worker + Redis + DB）

| 场景 | 结果 |
|---|---|
| **cancel 真停 job** | 触发 run → 立即 cancel → pending job 全→cancelled，run→cancelled ✓ |
| **worker 幂等跳过 cancelled** | cancelled job 被 arq 投递时 run_case_job_logic 终态守卫跳过，不执行不计数 ✓ |
| **aggregate 守卫防翻转** | cancel 后在跑 job 完成 aggregate，run 保持 cancelled（不被翻成 completed）✓ |
| **observability 反映真实状态** | queue-stats 正确显示 pending/running/failed死信/最老等待 ✓ |
| **真实 LLM 端到端**（PR #34 冒烟）| kimi-k3 生成真实文案 + glm-4.6 四维评分 `[8/9/10/8]` 落库 ✓ |

> 注：pristine 多 case 全绿受 glm-4.6 评分延迟方差影响（环境，非代码）——单 case 端到端已验证通过。
