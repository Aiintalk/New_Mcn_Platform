# 千川仿写 · 测试集录入模板（给张翀）

> 用途：评测系统需要一批"业务事实"测试例——给定【达人+产品+原版脚本】，让 AI 仿写，再用 4 维评分标准（钩子/转化/结构/人设）打分，回归对比不同版本。
> **你只填业务数据**（达人/产品/样板脚本）；怎么仿写、什么风格指令是**提示词侧**的事（版本管理），不用你管。
> 按下面表头填一张表（Excel/飞书均可），我来清洗导入。**第一批先给 5-10 条**，覆盖不同钩子类型/品类。

---

## 字段归属（先说清边界）

| 归属 | 字段 | 谁负责 |
|---|---|---|
| **测试集·业务数据（你填）** | 达人 / 达人人设 / 产品信息 / 参考原版脚本 | **张翀** |
| **测试集·元数据（你填）** | 样本名 / 标签 / 描述 | **张翀** |
| **提示词管理（不用你填）** | 改写指令、用哪些字段、风格策略 | 工具/版本侧（prompt 迭代） |

> 评测本质 = **同一份业务数据，跑不同提示词版本对比**。所以"怎么写/什么风格"是版本的事，测试例保持纯业务事实。

---

## 一、表头（7 列）

| 列 | 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| A | **样本名** | 管理 | ✅ | 唯一标识，建议「钩子类型 · 品类+卖点」，如`诱惑型 · 护肤套装大促逼单` |
| B | **达人** | **输入** | ✅ | 达人名，如`慧敏`、`桃园`（周会定的代表型达人） |
| C | **达人人设** | **输入** | ✅ | 一句话人设：风格+擅长，如`韩国欧尼慧敏：亲和种草风、擅长算账式逼单` |
| D | **产品信息** | **输入** | ✅ | 多行文本，写全：成分/核心卖点/价格机制/赠品/限时/适用人群/合规红线。**AI 只能基于这里的信息，不能编造** |
| E | **参考原版脚本** | **输入** | ✅ | 真实跑过的 60 秒千川脚本样板，用`【0-5s】【5-25s】…`时间码分段（AI 参考其结构仿写） |
| F | **标签** | 管理 | ✅ | 逗号分隔 3-4 个，建议「钩子类型,品类,场景/机制」，如`诱惑型,护肤,大促,囤货` |
| G | **描述** | 管理 | ⬜ | 一句话备注（可选） |

**类型说明**：
- **输入**（B/C/D/E）= 生成时渲染进 prompt 的业务数据，AI 据此仿写。
- **管理**（A/F/G）= 测试例的元数据（标识/分组/备注），不参与生成。
- ~~改写提示词~~ 已移出测试集——那是提示词/版本管理侧的事，不用填。

## 三、填写要点

1. **钩子类型**（标签第一个 + 样本名前缀）建议覆盖这几种，每类来 1-2 条：
   - `痛点型`（如"吃完火锅负罪感"切入）
   - `诱惑型`（价格/赠品/限时逼单）
   - `场景型`（办公室/出差/熬夜等代入）
   - `效果型`（前后对比/反差，如"脏油烟机→一擦净"）
2. **产品信息（D）写全写准**——这是 AI 唯一的产品事实来源，缺了 AI 会编或漏。价格机制/赠品/限时/合规红线都要写明。
3. **参考原版脚本（E）用时间码分段**（`【0-5s】…【5-25s】…`），是真实跑过的 60 秒脚本，AI 学它的节奏结构。
4. **合规红线写在产品信息里**（如食品"不能承诺具体减重斤数"、医疗"不能替代药物"）——AI 会从产品信息里读到并遵守。
5. **达人（B/C）**：第一批建议聚焦周会定的代表达人（**慧敏、桃园**），人设（C）固定后可复用。
