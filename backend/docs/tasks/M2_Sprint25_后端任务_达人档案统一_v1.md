# M2 Sprint25 后端任务：达人档案统一 v1

> 开发状态：已完成，等待产品经理验收；未执行生产数据库迁移、部署或上线。

## 目标

以正式 `kols.id` 贯通人格定位、入驻资料、报告历史和红人工作台七字段，关闭旧后端并行写入口，并保证当前运营资料隔离、非空内容不被静默覆盖。

## 开发范围

1. 幂等迁移为 `persona_reports`、`kol_intake_links`、`kol_intake_operator_sessions` 增加可空 `kol_id` 外键和索引，历史不回填。
2. 正式达人分页搜索和当前运营绑定入驻资料查询。
3. 生成请求、报告、Output、日志和同步使用同一 `kol_id`。
4. 定位字段空值自动写入、非空字段级覆盖；五项事实只接受报告原文证据且只填空。
5. 工作台七字段读取、单字段写入和最新报告补空。
6. 红人管理禁止写定位字段；旧素材库移除正式档案写接口。
7. 下游统一上下文七字段分段兼容。

## 不做

- 不按姓名回填或匹配历史记录。
- 不新增第二套档案表、版本表或回滚表。
- 不执行生产数据库迁移，不部署、不上线。
