# M2 Sprint 24 后端任务：红人工作台生产迁移链路 v1（修复 Bug）

## 目标

修复“应用代码已读取 migration 050 字段，但既有数据库未执行 050，导致素材库详情统一 HTTP 500”的部署链路缺口。

## 范围

- 先用隔离 PostgreSQL schema 稳定复现 050 前缺列。
- 新增按文件顺序执行的数据库迁移账本：校验和、单文件事务、并发锁、旧库显式基线。
- 已登记迁移不得重复执行，避免历史 seed 重放。
- 050 后验证旧记录、新媒体字段和第二次执行。
- 不改素材库业务接口，不新增用户可见字段，不执行生产数据库变更。

## 验收标准

- 迁移前查询 050 字段出现 `UndefinedColumnError`；迁移后 8 个字段存在且旧记录保持。
- 第二次执行 050 不报错、不改数据。
- 迁移执行器拒绝无基线接管既有库，拒绝校验和漂移。
- 相同数字前缀迁移均按完整文件名登记。
- 已登记 seed 第二次不执行。
- 素材库列表、详情、创建、编辑、视频兼容和旧记录读取的相关测试通过。

## 不做

- 不改线上数据库，不读取线上密钥。
- 不合并 `main`，不部署。
- 不顺手修复历史空库 031 seed 对模型 ID 的依赖。
