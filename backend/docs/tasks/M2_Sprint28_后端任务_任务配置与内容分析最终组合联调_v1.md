# M2 Sprint28 后端任务：任务配置与内容分析最终组合联调 v1

## 状态

开发联合验收阶段。两侧独立验收差异已在专用工作树完成语义组合；本任务不代表真实飞书/模型联调、生产迁移、提交、发布或上线完成。

## 目标

1. 在同一后端进程内由应用生命周期构造并注册内容分析运行提供器，任务配置只调用 `execute` 与 `redeliver`。
2. 保持任务配置选择范围、飞书运行时关系事实、每日项目实例、周账号去重实例和周批次收尾合同一致。
3. 组合迁移 059 与 060、接口/数据库/权限唯一事实源、测试隔离、前后端运行监控与状态显示。
4. 用假飞书网关、假模型、固定时钟和隔离测试数据库证明完整执行、空日报、失败关闭、周批、重试和幂等，不产生真实外部调用。

## 本轮组合修复

- 运行配置或资源在读取飞书前失败时，保留输入跳过、真实失败层与原因；未知结构仍按严格合同关闭。
- 仅投递失败不伪造输入已读或内部结果成功；已确认的不可变结果仍由重试来源合同绑定。
- 内容执行器主动产生 `DEADLINE_EXCEEDED` 时统一持久化为 `failure_stage=timeout`，页面可识别显示。
- 调度与内容存储共同要求系统服务账号存在、未删除、启用且为管理员。
- 调度循环补扫当前时刻以前最近的日/周固定时点，进程延迟或恢复不会因错过精确分钟而漏建；重复扫描由既有业务键幂等收敛。
- 前端补齐系统内部重试类型，并移除当前运行结果的联调占位文案。
- 第二轮把普通日报/账号的输入跳过结果限制为失败闭集；仅投递运行资源失败保持跳过状态并携带已核验的原结果/文档身份，支持连续补投。
- 补偿扫描用固定时点计算业务窗口、用实际恢复时间生成截止时间，并恢复数据库已持久化的正式自动待执行队列，不受当前范围变化影响。
- 标准 `.env` 内容分析配置经统一 Settings 显式注入运行提供器，投递身份也使用精确字段闭集。

## 禁止与边界

- 不修改两个受保护源工作树，不改写其历史。
- 不新增第三个跨模块方法、公共接口、数据表、状态枚举或页面。
- 不真实调用飞书、模型或付费服务，不连接生产数据库，不执行生产迁移或正式调度。
- 不暂存、提交、推送、创建合并请求、合并、部署或发布。

## 验证顺序

定向红绿 → 差异与安全扫描 → 冻结新指纹 → 三线短复审；只有 P0/P1 清零后才运行联合专项、后端主体全量、正式覆盖率及前端完整门禁。
