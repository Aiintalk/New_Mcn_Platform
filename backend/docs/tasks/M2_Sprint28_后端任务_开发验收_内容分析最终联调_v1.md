- [x] 项目库接口分页、项目隔离、人工加入、停用/恢复和人工开头补标具备标准信封与操作日志。

- [x] 重试模式及来源字段按运行类型闭集；已有非投递阶段失败的正式收尾允许完整人工重试，且同时绑定本次重试 TaskJob、原失败任务、批次和最新自动收尾版本；仅投递失败不得升级成完整执行。投递失败只走 `redeliver`，新运行键复用原内部结果键/文档键，来源无效按合同错误保持仅投递上下文，旧补投不能覆盖新周报。
