## 二、实现范围

1. 新增 `FeishuReadonlyClient`（飞书只读客户端协议）、`FeishuRecordPage`（分页合同）、`FeishuContentReader`（完整读取与账号结果派生）和 `FeishuContentTableConfig`（非敏感表定位）。真实网络客户端及凭据由后续联调环境注入。
2. 映射 `SecUid`、视频 ID、标题、字幕、发布/同步时间和点赞/评论/分享/收藏；外部播放链接和内网播放链接仅作来源追溯与运营回看。
3. 只有只读鉴权、字段清单和所有分页完整成功，才按显式任务账号和窗口派生 `SUCCESS_WITH_CONTENT` 或 `SUCCESS_WITHOUT_CONTENT`；任何鉴权、字段、单次请求超时、读取或分页异常均派生 `FAILED`，不生成假空日报。
4. 分页同时校验 `has_more`、下一页游标、游标重复、结束游标和可选总数；同一稳定作品保留最新采集值。
5. 内容标准输入新增标题与运营回看链接，删除逐条同步状态、媒体读取状态、第一画面、视觉证据和镜头输出。播放量不进入飞书映射、排序或判断。
6. 缺字幕内容保留发布量和四项互动统计，由程序直接标为“无法判断”，不调用结构化分析器或项目判断器。
7. 飞书完整读取且项目全部账号窗口内为零内容时，生成结构化无内容摘要，包含读取来源、已检查账号、窗口、完成时间及五项零计数。
8. 空日报不挂载保存库中既有的跨项目候选，与“本次新增 0 条”保持一致；全局既有候选池仍作为独立结果保留。
9. 自动入库只要至少有一条合法、非空的项目适配理由；理由维度仍使用闭集枚举，不再要求四个可选维度全部出现。
