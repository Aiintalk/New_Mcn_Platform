| 收尾副作用边界 | fake 执行器证明收尾不读取输入表、项目上下文或模型，不重复账号分析，也不写项目内容库、跨项目机会或账号基准；测试账号不创建正式收尾。 |
| 系统账号 | 开关默认关闭；账号缺失/禁用关闭失败且不创建任务。 |
| 四层状态 | 覆盖数据源、分析、内部结果、投递、无内容、未运行与超时语义。 |
| 报告根目录门禁 | 全空白保存为 `NULL`；自动日/周和测试缺根目录时落 `not_run/REPORT_ROOT_REF_MISSING` 且执行器零调用，候选仍可浏览；旧空根目录任务拒绝重试。 |
| 重试与并发终态 | 覆盖重投递抛异常或返回非法合同结果后仍只重投递、两会话相同请求只执行一次、旧测试任务不升级正式范围、内部重试不改窗口/截止、迟到结果不覆盖超时。 |
| 可恢复长任务 | 覆盖首个实例阻塞时整批任务已可由另一会话观察；超时条件更新与迟到结果保护保持，应用关闭不泄漏协程。 |
| 管理接口 | 九个接口保持管理员专用；周测试账号来自全部入驻成功且必要预检通过项目，正式周调度仍只用已选就绪范围；概览返回可编辑根目录、运行历史账号统一哈希、配置审计只留布尔值。 |
| 测试请求幂等 | 日/周测试同一规范化请求编号的串行或并发重复送达返回同一任务且执行一次；不同编号创建不同任务。 |
| 测试/正式隔离 | 正式三键保持稳定；测试内部结果键、文档键和运行键均进入含规范化请求编号的命名空间；测试与正式、不同测试请求互不冲突，手动/内部重试继承原键。 |
| 结果可见与脱敏 | 运行接口返回内部结构化结果编号与飞书文档链接，同时不回传账号明文、报告根目录引用或飞书行。 |

| 空值与输入边界 | 周账号展示名可空；测试/重试请求编号去空白后必须为 1 至 128 个字符。 |
