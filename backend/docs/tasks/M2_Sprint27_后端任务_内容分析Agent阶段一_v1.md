# M2 Sprint27 后端任务：内容分析 Agent 阶段一 v1

> 状态：开发侧离线验收已完成，等待主产品经理独立审核。未合并、未部署、未上线。
> 正式产品依据：外部 PM（产品经理）文档《M2 对标内容分析智能体需求文档》v1.6；外部文件只读，不复制、不修改、不纳入仓库。

## 一、任务目标

在不新增接口、数据表、迁移、调度、前端和真实模型调用的前提下，交付数据源与分析器均可替换的离线内核，用自动化测试锁定阶段一可以确定的计算、证据与项目隔离边界。

## 二、开发范围

1. 建立不可变领域对象，表达内容来源、稳定身份、最新互动值、证据、项目上下文、业务状态、日报和内容库候选。
2. 实现中国时区下的最近 3 个与 30 个完整自然日窗口、稳定键去重、人设点赞五项基准、每账号千川点赞前 3 候选和播放量不可用处理。
3. 定义 `ContentAnalyzer`（可注入的异步内容分析协议），测试只使用模拟分析器；共享基础分析可复用，项目适配判断必须分项目执行。
4. 实现 `ContentAnalysisEngine`（离线内容分析编排器），输出项目日报、分类和互动概览、0—3 条人设/千川机会、待入库候选与方法级跨项目候选。
5. 强制证据保护：缺少字幕可继续；视频不可读时不保留确定镜头或第一画面结论；来源商品说法不得升格为当前项目已确认事实。

## 三、数据与测试输入口径

- 目标飞书 Base（多维表格）只读地址已解析，但本会话令牌缺少 `base:table:read`（读取多维表格数据的权限）。因此本轮没有读取或提交原始 2098 条；这是访问权限不足，不是数据不存在。
- `phase1_anonymized.json`（阶段一匿名冻结样本）仅含 3 条合成标准输入，依据 v1.6 已核验的字段、缺字幕、播放量 0 不可用等边界事实，并结合关系快照的多项目结构特征。
- 冻结样本不含真实姓名、真实账号、本机绝对路径、长篇转写或预制主分类，不可作为生产数据源。

## 五、明确不做

- 不做正式数据接口、生产飞书读取、数据库/迁移、路由、调度、前端、真实项目验收。
- 不做可读视频的完整镜头验收，不调用真实或付费模型。
- 不生成公司级日报，不构造互动时间序列或增长趋势。
- 不实际持久化日报、基准、内容库或跨项目候选，不联调下游仿写读取。
- 不建设人工入库内容补标/回写、库生命周期、停用/恢复或编辑/版本能力。

## 六、验收准入

1. 38 条内容分析聚焦测试全部通过。
2. `unit + integration`（单元测试与集成测试）最大回归在正确后端目录下无失败。
3. 仓库覆盖率分层门禁给出可重复的完整证据，无论结果均如实记录。
4. `compileall`（Python 语法编译检查）和 `git diff --check`（Git 差异格式检查）通过。
5. README（项目说明）、PM 状态、任务、测试和验收文档全部落档，且不虚构生产能力。
