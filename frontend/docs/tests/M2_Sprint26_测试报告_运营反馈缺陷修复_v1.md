## 重点回归

- BUG-01：运营入口只表达“人格定位”，管理员仍保留正式红人创建入口；人格完成和历史报告均使用报告绑定的同一 `kol_id` 进入工作台。
- BUG-02：失败原因持续显示，输入保留，可原地重试；成功后编辑脚本、类型或商品会立即使旧结果失效并关闭保存；审核中修改输入后，旧请求的迟到失败不会污染新输入。
- BUG-03：失败流显示真实任务编号和原因，保留输入，可重试；未完成或失败状态不开放保存。
- BUG-04：文件、关键帧、文案和 `ready` 状态同时满足才可分析；左右两侧独立维护处理请求代次，替换、删除或人工修改文案会立即使旧请求失效；截帧、转录、重试转录各异步写回点均校验代次，旧文件响应不能污染新文件或误开分析门禁；输入变化也会立即关闭旧报告的保存和导出。
