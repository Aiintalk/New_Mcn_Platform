- 人格定位沿用原三步页，没有新增第二套页面。
- 正式达人列表展示姓名、账号、抖音号和七字段完整度；支持搜索、分页和选择快照。
- 选择后只请求该正式编号下当前运营可见的最新入驻资料；无资料时保留上传入口。
- 生成请求携带正式 `kol_id`；报告完成后展示自动写入状态和字段级覆盖对话框。
- 生成中达人被删除或模型流中断时显示失败，不把部分正文作为正式报告；同步失败显示真实失败原因。
- 人格档案与内容规划默认分别保留，可独立选择是否覆盖；关闭对话框等同保留。
- 从历史记录重新打开仍恢复未处理的逐字段覆盖确认，默认继续保留。
- 工作台人物档案展示七字段、完整度和单字段编辑；最新报告按钮只补空事实字段。
- 红人管理与旧素材库只保留摘要和工作台跳转，没有平行正式编辑入口。
