## 1. 目标

在现有管理端样式与请求层内提供管理员专用的“智能体任务配置”页面。首期只展示内容分析身份，让管理员持续配置项目范围、只读核对项目输入，并查看隔离的运行状态、详情、受控测试和单项目失败重试。

## 2. 开发范围

1. 新增管理员路由 `/admin/agent-tasks` 和管理端导航入口；运营端不增加入口。
2. 页面保留共用智能体切换层的当前身份表达，但首期只显示“内容分析”，不展示其他智能体灰色入口。
3. 只提供“任务与输入”“运行监控”两个页签。
4. 只读展示两个固定任务及正式合同：每日 00:00 / 最近 3 个完整自然日；每周一 01:00 / 最近 30 个完整自然日。
5. 分页、搜索和筛选入驻成功项目；支持跨分页勾选、取消与整体保存当前内容分析项目范围。
6. 清楚展示已选可运行、已选配置缺失、未选择三态，以及必要配置和非必要上下文缺失原因。
7. 用只读抽屉展示项目输入模块、来源、更新时间、内容和缺失原因。
8. 运行监控支持任务、项目、状态、运行类型和日期筛选，展示项目隔离的运行记录与详情。
9. 支持管理员发起受控测试，并仅对失败记录提供单项目重试入口。
10. 页面全部业务时间固定按 `Asia/Shanghai`（上海/北京时间时区）展示，不随浏览器本地时区偏移。
11. 兼容通用任务页的 `not_run`（未运行）状态显示和筛选，不映射为失败或取消。
12. 复用现有页面卡片、表格、徽标、弹窗、抽屉与响应式样式，不建设独立运行治理前端。

## 3. 输入与输出

### 3.1 输入

- 后端概览、固定任务、项目范围、项目输入、运行列表和运行详情的标准响应数据。
- 管理员的项目关键词、范围状态、分页、勾选结果和保存操作。
- 管理员的运行筛选条件、受控测试任务/项目选择和失败重试确认。

### 3.2 输出

- 内容分析当前身份、阶段说明、状态摘要和两个固定任务卡片。
- 可持续保存的项目选择界面及三态、缺失原因和最近保存信息。
- 只读项目输入抽屉。
- 项目级运行监控表、详情日志、受控摘要和重试入口。
- 所有正式结果位置统一显示“待最终联调”。
- 所有 JSON（结构化数据）请求继续通过 `frontend/src/api/request.ts`，页面不直连外部服务。

## 5. 明确不做

- 不展示或接入直播复盘、千川内容仿写、人设仿写等其他智能体。
- 不向项目运营开放页面或项目级只读权限。
- 不提供任务总开关、自定义触发时间、多计划、提示词、通知、成本或人工结果确认。
- 不调用真实内容分析智能体，不展示伪造的专业结果。
- 不写日报、内容库或 `Output`，不提供可用正式结果入口。
- 不实现真实自动生产触发、最终联调或真实数据库迁移；本地提交之外，不推送、合并、部署或上线。
