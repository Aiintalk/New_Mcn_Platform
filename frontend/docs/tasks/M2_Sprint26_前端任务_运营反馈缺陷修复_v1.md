# M2 Sprint26 前端任务：运营反馈缺陷修复 v1

> 开发状态：代码与聚焦测试已完成，等待全量门禁、真实浏览器核验、独立技术复审和产品经理验收；未合并、未部署、未上线。

## 目标

修正红人工作台入口承诺，并为三个千川工具建立持续可见、可重试且不丢输入的失败闭环。

## 开发范围

1. 红人工作台运营入口从“新增红人”收口为“人格定位”；仅管理员显示“前往红人管理新增”。
2. 人格定位报告生成和同步成功后，可进入同一 `kol_id` 的工作台人物档案页，或返回运营红人列表。
3. 脚本预审防御性校验后端结果；失败面板持续显示，保留两份脚本、模式和商品，并可原地重试；保存携带成功任务编号。
4. 脚本复盘只把内容事件拼入报告，只有收到完成事件且报告非空才开放保存/导出；失败保留脚本和投放数据，显示任务编号和重新生成。
5. 剪辑预审为两侧分别建立未上传、待处理、截帧中、转录中、已就绪、失败状态；双侧就绪后才允许分析。
6. 截帧失败显示“重试截帧”；转录失败保留帧并显示“重试转录”；手工补充非空文案可恢复就绪。
7. 分析空结果或异常不展示保存、导出，保留两侧已处理数据并允许重新预审。

## 权限与范围边界

- 不新增运营创建正式红人的能力，不创建第二套人格定位页，不按姓名匹配达人。
- 不修改剪辑预审固定 8 帧策略，不做输出质量或页面视觉重构。
- VERIFY-01 只有在最新代码仍可复现时才允许改代码；不能复现则仅记录版本和浏览器证据。
