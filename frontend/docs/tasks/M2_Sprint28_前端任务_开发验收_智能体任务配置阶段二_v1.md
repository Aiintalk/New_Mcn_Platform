## 2. 实现清单

| 类别 | 开发侧实现 |
|---|---|
| 配置 | 回显和编辑共享报告根目录，与跨分页项目范围一起持续保存；未配置时明确提示自动/测试只落未运行且不调用执行器；页面不提供两张飞书输入表配置。 |
| 固定任务 | 保留每日 00:00 / 3 天、每周一 01:00 / 30 天北京时间合同，并如实提示调度默认关闭、当前未启用。 |
| 受控测试 | 日任务可选择任何必要配置通过的项目且不改变持续范围；周任务分页读取全部合格项目汇总的账号候选并展示关联项目，同样不要求已勾选；请求体不携带客户端项目列表或目录。 |
| 请求幂等 | 测试与重试生成 `request_id`；网络失败后同一弹窗再次确认复用，成功、关闭或切换对象后重置；周账号搜索、翻页或响应换页会清空消失对象和原请求号；原生 UUID 不可用时提供测试环境回退。 |
| 草稿保护 | 延迟概览响应只初始化未编辑的报告根目录，不覆盖管理员本地未保存草稿。 |
| 账号隐私 | 周候选没有账号名称时仅显示稳定脱敏尾号，提交值仍使用接口返回的完整账号键。 |
| 运行监控 | 支持项目与账号筛选，区分项目实例、脱敏账号实例和内部周批次收尾实例；收尾显示批次编号与账号数量，不冒充账号，展示 `retry`、`manual_retry` 和 `internal_retry` 的明确中文类型。 |
| 四层结果 | 列表和详情展示数据库预检、飞书关系、内部结果、投递及失败阶段；正式与测试运行在有值时都显示只读内部结果编号，零视频显示“无内容（空日报）”。 |
| 文档入口 | 仅合法 HTTP/HTTPS 地址显示新窗口链接，并设置 `noopener noreferrer`；内部结果编号不伪造详情链接；结果区不展示账号明文或报告根目录引用；无结果时显示“暂无结果”。 |
| 分阶段重试 | 投递失败明确“仅重试投递，不重复分析”，其他失败明确“完整重试”，模式判断仍由后端执行。 |
| 既有能力 | 保留两个页签、只读输入抽屉、三态项目范围、跨分页选择、请求竞态保护、北京时间格式化和表格内部滚动。 |
