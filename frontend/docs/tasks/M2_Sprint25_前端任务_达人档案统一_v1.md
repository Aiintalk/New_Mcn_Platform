# M2 Sprint25 前端任务：达人档案统一 v1

## 目标

沿用现有人格定位三步页完成正式达人绑定和覆盖确认，把红人工作台人物档案升级为七字段唯一编辑入口，并将红人管理、旧素材库收口为只读摘要和跳转。

## 开发范围

1. 人格页显示可搜索正式达人、账号与 `x/7` 完整度；加载失败可重试。
2. 选择达人后只查询该编号当前运营可见的最近入驻资料；没有资料仍可上传。
3. 生成请求必带 `kol_id`；流结束后展示空字段写入结果和默认保留的字段级覆盖对话框。
4. 工作台分“定位与规划”“人物事实素材”展示七字段，单字段保存/取消，支持最新报告补空。
5. 红人管理和素材库不再提供人格档案、内容规划保存入口，保留只读摘要和工作台跳转。
6. 真实页面在 1440x900、1024x768 无横向滚动、遮挡或按钮移出视口。

## 不做

- 不新建人格定位页面或更改三步主流程。
- 不展示未绑定会话，不按姓名猜测关联。
- 不改文案、直播和复盘页面流程。

## 验收

以 `docs/superpowers/plans/2026-08-03-kol-persona-profile-unification.md` Task 3、Task 4 和 Task 5 的测试矩阵为准；JSON 请求必须使用 `request.ts`。
